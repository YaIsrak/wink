# Scope

## MVP features

- Post creation (photo or caption, or both)
- Likes
- Comments
- Follow / following
- Real-time direct messaging — **only between mutual follows**
- Notifications (likes, comments, follows, messages)
- Search (users, posts)
- Explore/discover feed

## Explicitly out of scope (for now)

- Stories (24h disappearing posts)
- Video posts / live streaming
- Groups/communities
- Monetization / payments / ads

## DECIDE LATER

- Admin/moderation tooling
- Multi-role permissions beyond ownership-based checks
