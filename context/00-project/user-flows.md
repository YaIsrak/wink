# User Flows

## Primary flow

1. **Sign up** (email, via Supabase Auth)
2. **Onboarding** — complete profile (username, avatar, bio, etc.)
3. **Home feed** — posts from followed users; "Getting Started" checklist
   shown until complete
4. **Create post** — photo and/or caption
5. **Engage** — like / comment on posts
6. **Follow / unfollow** users
7. **Explore** — discover posts/users outside your follow graph
8. **Search** — find users or posts
9. **Direct messages** — only with mutual follows; real-time
10. **Notifications** — likes, comments, follows, messages

## Gamification touchpoints along the flow

- Profile completion % banner from onboarding until 100% complete.
- "Getting Started" checklist: complete profile → follow 3 people → make
  first post → send first DM. Each step checked off as completed;
  dismissible once fully done.
