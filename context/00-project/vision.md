# Vision

**Wink** (working title) is a social media web app where general users
post photos or captions, follow each other, like and comment, message
mutual follows in real time, and get notified of activity.

## Problem

A simple, self-built social platform to demonstrate full-stack product
skills as a portfolio piece — covering auth, real-time features, media
handling, and a polished, gamified UX.

## Who it's for

General/public users. Single role — no admin/moderator tier in this phase.

## Scale target

Personal portfolio project; must comfortably handle at least ~100
concurrent users. Not built for viral/large-scale growth.
